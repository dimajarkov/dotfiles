# Native sessions own review feedback

Hunk feedback is bound to the original native coding-agent session and delivered through its native admission interface, while Herdr manages pane placement only.
Terminal identity checks followed by terminal pasting cannot atomically protect against an occupant replacement and do not provide durable busy-session queue semantics.
A private durable review runtime retains immutable context and uncertain batches rather than transferring feedback to whichever agent now occupies a pane.
