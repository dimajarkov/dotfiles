# The two tab bars in devaslife's Herdr and Neovim setup

## What the bottom bar shows

The `claude`, `nvim`, and `example project` labels are Herdr terminal tabs in one workspace, with `nvim` selected.
The [video's 07:59 chapter](https://www.youtube.com/watch?v=BhGWcQtq408&t=479s) names Herdr, and the [author's Claude still](https://storage.ghost.io/c/d0/bc/d0bc0a46-ecd4-4f66-8377-998e00d2e3f7/content/images/2026/11/2026-11-01-Neovim-setup---02-Agent-next-to-Neovim.jpg) shows the same bottom row without the Neovim tabline.
Herdr renders the [tabs of the focused workspace](https://github.com/herdrdev/herdr/blob/v0.9.5/src/client/shell/tabs.rs#L7-L34), its own [`+` button](https://github.com/herdrdev/herdr/blob/v0.9.5/src/client/shell/tabs.rs#L160-L179), and the compact sidebar's [`»` expander](https://github.com/herdrdev/herdr/blob/v0.9.5/src/client/shell/sidebar.rs#L173-L188).
The [author's Herdr config](https://github.com/craftzdog/dotfiles/blob/bb582542799746177b8e2b2c7e7b1e301e34514c/dot_config/herdr/config.toml#L1-L15) sets `tab_bar_position = "bottom"`, `hide_tab_bar_when_single_tab = true`, `sidebar_start_collapsed = true`, `pane_gaps = false`, and the `solarized` Herdr theme.
The [Herdr UI docs](https://herdr.dev/tui/docs/configuration/#ui-and-sidebar) confirm that `tab_bar_position` controls the desktop pane layout and defaults to `"top"`.
The [config reference](https://herdr.dev/tui/docs/config-reference/#ui) distinguishes starting collapsed from hiding the sidebar entirely: `"compact"` keeps a narrow rail, while `"hidden"` removes it.
Takuya's [terminal config](https://github.com/craftzdog/dotfiles/blob/master/dot_config/ghostty/config) supplies the translucent Ghostty window, PlemolJP Console NF font, and Solarized Dark - Vivid terminal palette, not either tab row.
Bottom placement has been available upstream since [Herdr v0.8.0](https://github.com/herdrdev/herdr/blob/v0.9.5/CHANGELOG.md#L337-L342), so it needs no fork.
Takuya's [October 20 config commit](https://github.com/craftzdog/dotfiles/commit/09feadf1ff7aa4cd0b68e50b20f9aabe102e650d) already has the bottom-bar settings, and his [October 21 fix](https://github.com/craftzdog/dotfiles/commit/d89915956998a64141d3184bb3dd8f0e21d29706) names Homebrew Herdr 0.9.5, though the exact binary in the video is not established.

## What the top bar shows

The top row in the supplied [video](https://www.youtube.com/watch?v=BhGWcQtq408) frame shows `keymaps.lua`, `init.lua`, and a highlighted `CodeDiff Explorer` label, while the [author's corresponding article still](https://storage.ghost.io/c/d0/bc/d0bc0a46-ecd4-4f66-8377-998e00d2e3f7/content/images/2026/11/2026-11-01-Neovim-setup---37-codediff-explorer.jpg) shows the same review layout with `git.lua` in the highlighted third slot instead.
The top row is Neovim's built-in `tabline` rendered by the author's [custom Lua](https://github.com/craftzdog/dotfiles/blob/86edf45783045c56cdc74bf0a83f2fffcb7be828/dot_config/nvim/lua/craftzdog/utils/tabline.lua), not a bufferline plugin or a terminal tab bar, as the [author's tabline spec](https://www.devas.life/effective-neovim-setup-for-agentic-coding-towards-2027/#23-tabline) and [UI setup](https://github.com/craftzdog/dotfiles/blob/86edf45783045c56cdc74bf0a83f2fffcb7be828/dot_config/nvim/lua/craftzdog/plugins/ui.lua#L5-L17) confirm.
The UI sets `showtabline = 1`, so the row only appears with at least two [Neovim tab pages](https://neovim.io/doc/user/tabpage/#setting-tabline).
A tab page is a layout of one or more windows, a window displays a buffer, and a buffer need not have a visible window, so the number of tab labels does not count open files or splits ([Neovim window help](https://neovim.io/doc/user/windows/), [tab-page help](https://neovim.io/doc/user/tabpage/#tabpage-intro)).
For each tab page the [renderer](https://github.com/craftzdog/dotfiles/blob/86edf45783045c56cdc74bf0a83f2fffcb7be828/dot_config/nvim/lua/craftzdog/utils/tabline.lua#L97-L150) uses `tabpagewinnr()` to pick the current window's buffer from `tabpagebuflist()`, so changing the focused window or its buffer can change a label without opening a new tab.
The [renderer](https://github.com/craftzdog/dotfiles/blob/86edf45783045c56cdc74bf0a83f2fffcb7be828/dot_config/nvim/lua/craftzdog/utils/tabline.lua#L4-L94) draws padded trapezoids with Powerline separator glyphs, uses Solarized Osaka colors with bold `base4` on yellow for the current tab and `base0` on `base02` for the others, and gets ordinary file icons from `mini.icons`.
The [label code](https://github.com/craftzdog/dotfiles/blob/86edf45783045c56cdc74bf0a83f2fffcb7be828/dot_config/nvim/lua/craftzdog/utils/tabline.lua#L58-L119) uses the file basename, shortens long names to the first 17 bytes plus `…` when they exceed 20 bytes, adds `[+]` if the displayed buffer is modified, and handles terminal, unnamed, and Oil directory buffers separately.
The [renderer emits tab-click regions](https://github.com/craftzdog/dotfiles/blob/86edf45783045c56cdc74bf0a83f2fffcb7be828/dot_config/nvim/lua/craftzdog/utils/tabline.lua#L124-L133), but the author's [options disable the mouse](https://github.com/craftzdog/dotfiles/blob/86edf45783045c56cdc74bf0a83f2fffcb7be828/dot_config/nvim/lua/craftzdog/config/options.lua#L47-L48).

## How to navigate it

In Normal mode, `te` runs `:tabedit` with no filename to open an empty tab, `Tab` runs `:tabnext`, and `Shift-Tab` runs `:tabprev` ([author's core mappings](https://github.com/craftzdog/dotfiles/blob/86edf45783045c56cdc74bf0a83f2fffcb7be828/dot_config/nvim/lua/craftzdog/config/keymaps.lua#L35-L38), [Neovim tab commands](https://neovim.io/doc/user/tabpage/#tabpage-commands)).
Native `:tabedit <file>` opens a named file in a new tab, `:tabclose` closes the current tab, and `:tabs` lists the tab pages and their windows ([Neovim tab commands](https://neovim.io/doc/user/tabpage/#tabpage-commands)).
The author's Normal-mode `ss` and `sv` create horizontal and vertical splits below and to the right, respectively, while `sh`, `sj`, `sk`, and `sl` focus the neighboring window left, down, up, and right within the tab ([core mappings](https://github.com/craftzdog/dotfiles/blob/86edf45783045c56cdc74bf0a83f2fffcb7be828/dot_config/nvim/lua/craftzdog/config/keymaps.lua#L39-L46), [split options](https://github.com/craftzdog/dotfiles/blob/86edf45783045c56cdc74bf0a83f2fffcb7be828/dot_config/nvim/lua/craftzdog/config/options.lua#L59-L65)).
For buffers rather than tabs, `\\` opens the `snacks.nvim` buffer picker, which jumps to a window already displaying the selected buffer even in another tab, or switches the current window to that buffer if none displays it ([picker mapping](https://github.com/craftzdog/dotfiles/blob/86edf45783045c56cdc74bf0a83f2fffcb7be828/dot_config/nvim/lua/craftzdog/plugins/keymaps.lua#L119-L146)).

## CodeDiff and neighboring editor UI

`esmuellert/codediff.nvim` is a separately installed [plugin](https://github.com/craftzdog/dotfiles/blob/86edf45783045c56cdc74bf0a83f2fffcb7be828/dot_config/nvim/lua/craftzdog/plugins/init.lua#L6-L14) that opens its [side-by-side view in a new tab page](https://github.com/esmuellert/codediff.nvim/blob/eee54e78e6f152a6eb03b090e95f7576c96a5ad9/lua/codediff/ui/view/side_by_side/create.lua#L302-L325).
The [CodeDiff Explorer](https://github.com/esmuellert/codediff.nvim/blob/eee54e78e6f152a6eb03b090e95f7576c96a5ad9/lua/codediff/ui/explorer/render.lua#L23-L55) is a read-only split on the left by default, not a separate tab or the general file explorer, and its buffer is named `CodeDiff Explorer [<tabpage-id>]` in the public plugin source.
The two code columns are windows within that same tab, and the Explorer buffer name explains why the custom tab can show `CodeDiff Explorer…` when the left split has focus and a filename such as `git.lua` when a diff window has focus ([CodeDiff split source](https://github.com/esmuellert/codediff.nvim/blob/eee54e78e6f152a6eb03b090e95f7576c96a5ad9/lua/codediff/ui/explorer/render.lua#L23-L55), [tabline renderer](https://github.com/craftzdog/dotfiles/blob/86edf45783045c56cdc74bf0a83f2fffcb7be828/dot_config/nvim/lua/craftzdog/utils/tabline.lua#L85-L110)).
The author's [CodeDiff setup](https://github.com/craftzdog/dotfiles/blob/86edf45783045c56cdc74bf0a83f2fffcb7be828/dot_config/nvim/lua/craftzdog/plugins/ui.lua#L158-L175) uses a 50-column tree of changes with added and removed line counts, opens each file's diff as the Explorer cursor moves, and folds unchanged code with eight context lines and synchronized folds.
With Space as [leader](https://github.com/craftzdog/dotfiles/blob/86edf45783045c56cdc74bf0a83f2fffcb7be828/dot_config/nvim/lua/craftzdog/config/options.lua#L63-L65), the author's [CodeDiff mappings](https://github.com/craftzdog/dotfiles/blob/86edf45783045c56cdc74bf0a83f2fffcb7be828/dot_config/nvim/lua/craftzdog/plugins/keymaps.lua#L266-L272) are `Space dv` for `:CodeDiff` to toggle the diff view, `Space dh` for `:CodeDiff history %` to review the current file, and `Space dH` for `:CodeDiff history` to review the repository.
In the upstream [CodeDiff defaults](https://github.com/esmuellert/codediff.nvim/blob/eee54e78e6f152a6eb03b090e95f7576c96a5ad9/doc/codediff.txt#L323-L347), `Enter` selects an Explorer item, `Space e` focuses the Explorer with this leader setting, `]c` and `[c` jump between hunks, `]f` and `[f` jump between files, and `q` quits the review view.
The general file browser is instead `oil.nvim`, which `sf` opens as a centered floating directory buffer with a preview, and `h` and `q` navigate to the parent directory and close it ([author's file explorer section](https://www.devas.life/effective-neovim-setup-for-agentic-coding-towards-2027/#32-file-explorer), [Oil mapping](https://github.com/craftzdog/dotfiles/blob/86edf45783045c56cdc74bf0a83f2fffcb7be828/dot_config/nvim/lua/craftzdog/plugins/keymaps.lua#L20-L29)).
`incline.nvim` is the separate plugin that adds a filename and icon tag in the top-right corner of each window, with `[+]` for unsaved edits and smart hiding on the cursor line ([author's window labels section](https://www.devas.life/effective-neovim-setup-for-agentic-coding-towards-2027/#25-window-labels), [Incline setup](https://github.com/craftzdog/dotfiles/blob/86edf45783045c56cdc74bf0a83f2fffcb7be828/dot_config/nvim/lua/craftzdog/plugins/ui.lua#L139-L156)).
The Neovim row showing editor mode, Git branch, file path, and cursor location is the separate global `lualine.nvim` statusline, not the custom tabline ([author's statusline section](https://www.devas.life/effective-neovim-setup-for-agentic-coding-towards-2027/#24-statusline), [lualine setup](https://github.com/craftzdog/dotfiles/blob/86edf45783045c56cdc74bf0a83f2fffcb7be828/dot_config/nvim/lua/craftzdog/plugins/ui.lua#L58-L137)).

## Local adaptation

This repo uses Herdr's bottom row without changing its existing sidebar and prefix settings.
The Neovim tabline borrows Takuya's shapes and labeling but adapts the colors to the current theme.
It retains native `gt` and `gT` rather than intercepting `Tab`, which this repo uses as the Herdr prefix.
See the [current configuration notes](../../README.md#notes) for the CodeDiff mappings and update instructions.
