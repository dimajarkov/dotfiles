What each tool accomplishes

Nix and Home Manager cooperate, but they are not the same thing.

❄️

Nix: the immutable warehouse

  • ●Builds Pi from explicitly declared inputs.
  • ●Keeps outputs in unique paths under /nix/store.
  • ●Allows different versions to coexist instead of overwriting each other.
  • ●Makes upgrades and rollbacks switch references rather than mutate a program in place.
🏡

Home Manager: your household manifest

  • ●Reads your declarative user setup from home.nix.
  • ●Selects which Nix packages should appear in your user profile.
  • ●Manages stable links, shell configuration, and selected dotfiles.
  • ●Recreates the same intended environment from configuration instead of ad hoc installation history.

Decode the long Nix store path

store root /nix/store/ build identity p86k1i1gz0aqvz6hykh7qls8w5rw4bh0- package pi-coding-agent- version 0.84.1/bin/pi

Why the strange prefix?

It is Nix’s identity fingerprint for this exact output and its build inputs. It prevents unrelated builds from colliding. It is not merely the version number or a simple checksum of the executable.

Why is the version readable?

pi-coding-agent-0.84.1 is the human-readable package name. It lets you recognize the program without decoding the fingerprint.
